# FamilyFlow — Offline Family Budget Scheduler

## Author
Sapan Khadka

## Project Abstract
FamilyFlow is an offline budgeting and expense-scheduling application for new parents. Users can record expected income, recurring bills, and planned purchases with deadlines. The application will propose dates for flexible expenses based on projected available funds, flag potential shortfalls, and recalculate the schedule when information changes. It will use Python, Flask, and SQLite, storing data locally without requiring internet access. This is an individual project for CS445.
